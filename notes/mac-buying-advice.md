# 給家長的 Mac 選購建議（2026-09-16）

> 價格為 Apple 台灣**教育價**估算，升級選項價格請以 apple.com/tw-edu 當期為準。
> 記憶體與硬碟在 Mac 上都是**焊死的，買了不能升級**，所以這兩項要一次決定好。

## 一、如果「不做 3D」（Python、pygame、Godot 2D、網頁）

| 項目 | 建議 | 理由 |
|---|---|---|
| 機型 | MacBook Air 13" | 1.23kg，適合每天帶 |
| 晶片 | M5（標準版） | 2D 開發用不到更強的 GPU |
| 記憶體 | 16GB（標配） | 編輯器 + 瀏覽器綽綽有餘 |
| 儲存 | 512GB（標配） | 程式碼與文件佔不了多少空間 |
| 估價 | **約 NT$32,590** | 13" M5 教育價起跳 |

## 二、如果「一年內會做 3D」（Godot 3D、Unity、Blender）← 目前的規劃

| 項目 | 建議 | 理由 |
|---|---|---|
| 機型 | MacBook Air 13"（或 15"） | 學習階段的 3D 場景小，不需要 Pro 的散熱 |
| 晶片 | M5（標準版） | GPU 不是瓶頸；M5 Pro 要專業工作量才划算 |
| 記憶體 | **24GB** | Unity + Blender + 瀏覽器同開，16GB 會開始吃 swap |
| 儲存 | **1TB** | 一個 Unity 專案 10–30GB，加素材、Xcode 很快吃滿 512GB |
| 估價 | **約 NT$41,000–42,000** | 32,590 + 24GB 約 3,000 + 1TB 約 6,000 |

### 同價位的另一個選擇
MacBook Air **15"** 標配 16GB/1TB，教育價約 NT$39,500——螢幕大，做 3D 場景編輯較舒服；
代價是 1.51kg。若要 24GB 一樣得加價。

### 要不要買 MacBook Pro 14"
Pro 的實質差別是**有風扇**（連續算圖、烘焙光照不降速）與更好的螢幕，同規格約貴一萬多。
學習階段的 3D 只會讓烘焙從 2 分鐘變 3 分鐘，不影響學習。預算寬鬆想一次買到不煩惱才考慮。

## 三、不建議的選項

| 選項 | 為什麼不建議 |
|---|---|
| M5 Pro / M5 Max 機型 | 效能差距要到專業影片、大型 3D 專案才感覺得到 |
| 32GB 記憶體 | 對她這個階段的專案規模是多的，24GB 已足夠 |
| 512GB + 靠外接硬碟撐 3D | 專案放外接較慢、也容易忘記帶；不做 3D 才適合這招 |
| Mac mini（無螢幕） | 便宜約 6,000 元、效能更好，但不能帶著走 |

## 補充

- **Mac 做 3D 遊戲沒問題**：Godot 與 Unity 在 macOS 上都是完整支援。較弱的是 Unreal Engine，
  但那是大型 3A 專案的工具，不在我們的學習路線上。
- **要上架 iOS 只能用 Mac**，Windows 做不到，所以買 Mac 這個方向本身是對的。
