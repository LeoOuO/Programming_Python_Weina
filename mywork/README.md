# mywork —— 你的作業放這裡

**上課和寫作業，都在這個資料夾裡改檔案。**

外面那些 `lesson01/`、`lesson02/`… 是老師的教材，
老師會一直更新它們，所以**不要直接改外面的檔案**——
改了的話，下次更新教材就會打架。

## 怎麼用

1. 點兩下 `開始上課.command`，輸入今天的堂數
2. 今天要用的檔案就會被複製到 `mywork/lesson0N/`
3. 在那裡面寫、在那裡面執行

已經存在的檔案不會被蓋掉，所以放心點，點幾次都沒關係。

## 老師更新教材的時候

點兩下 `更新教材.command` 就好。這個資料夾裡的東西不會被動到。
