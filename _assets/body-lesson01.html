盒子裡的東西有兩種

字串 str（文字）

用引號包起來

name = "Rain"
job = "Swordsman"

可以相加 → 接在一起
"Fire" + "Mage" → "FireMage"

整數 int（數字）

沒有引號

hp = 100
atk = 18

可以做數學
100 + 18 → 118

"100" 和 100 不一樣。前者是「一串符號」，後者是「數量」。 "100" + "18" 會得到 "10018"！
現場示範這個陷阱：在終端機打 python3 進入互動模式，直接打 "100" + "18" 給她看，她會笑。
（互動模式離開用 exit()。這招之後拿來試任何一行程式都很好用。）
再示範 "100" + 18 → TypeError，對照上一堂學過的「錯誤訊息看得懂」。

f-string：把變數塞進句子裡

1) 三種寫法

print("Name: " + name)        # 用 + 接，只能接字串
print("HP:", hp)              # 用逗號，什麼都能印
print(f"{name} has {hp} HP")  # f-string，最好用

2) f-string 的規則

  • 引號前面加一個 f
  • 要放變數的地方用 大括號 { }
  • 大括號裡面可以直接算：f"total {atk * 2}"

如果 name = "Rain"、hp = 100，
print(f"{name} has {hp} HP") 會印出什麼？

答案：Rain has 100 HP。大括號被換掉，其他字原封不動。
之後全部用 f-string，不要再用 + 接字串——省掉「型別不同不能相加」的麻煩。
小測驗打錯字也沒關係，重點是她有沒有理解「大括號會被換成盒子裡的東西」。

Part 3

傷害公式

傷害其實就是一條算式

打開 02-damage.py改改看倍率和防禦力
atk = 18          # 我方攻擊
defense = 5       # 對方防禦
skill = 1.5       # 技能倍率

damage = (atk - defense) * skill     # → 19.5
print(f"damage {int(damage)}")       # → 19

運算子

+ 加- 減* 乘
/ 除// 除完取整% 餘數

兩個要記的

/ 算出來一定有小數點：10 / 2 → 5.0

int() 把小數點後面直接砍掉：int(19.9) → 19

重點不是運算子表，是「遊戲數值都是算出來的」這個概念。
讓她改 skill 看傷害怎麼變、改 defense 到比 atk 大 → 傷害變負的 → 問她「遊戲裡會有負傷害嗎？該怎麼辦？」（答案是 if，正好接到下一段）。
// 和 % 各講一個遊戲例子就好：// 算「經驗值夠升幾級」，% 算「還差多少到下一級」。不要展開。

Part 4

暴擊判定

讓電腦自己做決定

if：如果⋯⋯就⋯⋯

if roll >= 95:
    print("PERFECT CRITICAL!")
elif roll >= 80:
    print("CRITICAL HIT!")
elif roll <= 5:
    print("You missed")
else:
    print("Normal attack")

三個規則

  • 條件後面要有冒號 :
  • 下一行要縮排 4 格
  • 從上往下第一個成立的執行完就跳出去

比較

> < >= <= == 等於 != 不等於

== 是問「一樣嗎」，= 是「放進盒子」

「第一個成立的就跳出去」是今天最容易錯的觀念，下一頁會專門測。
== 和 = 的差別現在只要講一次，她之後一定會踩到，踩到時再回來講第二次比較有效。

順序寫反了會怎樣？

❌ 寫反的版本

if roll >= 80:
    print("CRITICAL HIT!")
elif roll >= 95:
    print("PERFECT CRITICAL!")

擲到 97 會印什麼？

✅ 正確的版本

if roll >= 95:
    print("PERFECT CRITICAL!")
elif roll >= 80:
    print("CRITICAL HIT!")

條件嚴格的放前面

答案

左邊擲到 97 會印 CRITICAL HIT!——因為 97 也 >= 80，第一條就成立了， 後面的 PERFECT CRITICAL! 永遠不會執行。這種 bug 不會報錯，只是遊戲怪怪的，最難抓。

兩個條件要同時看：and / or

打開 04-potion.py試不同的血量和藥水數
if hp < 30 and potions > 0:
    print("Drink a potion!")
elif hp < 30 and potions == 0:
    print("No potions left. RUN!")
elif hp >= 80 or potions >= 5:
    print("You are in good shape")
意思
and兩邊都成立
or任一邊成立
not反過來

遊戲裡到處都是：
「血量低且有藥水」才自動喝
「等級夠或有門票」才能進副本
