Part 1

for：重複固定次數

五連段攻擊

打開 01-combo.py執行，然後改成 8 連段
for i in range(5):
    print(f"第 {i} 下攻擊")
第 0 下攻擊 第 1 下攻擊 第 2 下攻擊 第 3 下攻擊 第 4 下攻擊

三個部分

  • range(5) 給出 0 1 2 3 4（五個數字，從 0 開始）
  • i 是一個盒子，每輪裝一個
  • 冒號 + 縮排 4 格，跟 if 一樣

想從 1 開始 → range(1, 6)

「從 0 開始」她一定會不習慣，這是程式的慣例，直接說「電腦數數從 0 開始，習慣就好」，不要哲學化。
現場出三個小題讓她口答：range(3)？range(2, 5)？range(1, 4) 跑幾次？
range(0, 10, 2) 讓她自己試，不要先講。

越打越痛：用 i 來算傷害

atk = 12

for i in range(1, 6):
    damage = atk * i
    print(f"第 {i} 下：{damage}")
第 1 下：12 第 2 下：24 第 3 下：36 第 4 下：48 第 5 下：60
i 不只是編號，可以拿來算——連段倍率、關卡難度、敵人數量都靠它。

for i in range(1, 6): print(i * 3) 印出來的最後一個數字是？

答案 15（i 最後是 5）。答錯通常是以為 range(1,6) 跑到 6。
延伸玩法（她如果很快）：print("⚔️" * i) 印出三角形，她會很喜歡。

把傷害加起來

打開 02-total.py執行看累積過程
total = 0                      # ① 先準備一個空的計數盒子

for i in range(1, 6):
    damage = 12 * i
    total = total + damage     # ② 每輪把新的加進去
    print(f"第 {i} 下 {damage}，目前累積 {total}")

print(f"總傷害：{total}")        # ③ 迴圈跑完才印

累加三步驟

① 迴圈外面歸零
② 迴圈裡面累加
③ 迴圈外面印結果

同一招能做什麼

總傷害、總金幣、總經驗、數次數（暴擊幾次、贏幾場）

最常見的兩個錯：total = 0 寫在迴圈裡面（每輪歸零，結果永遠是最後一下）、print 縮排進迴圈（印五次）。
兩種都故意示範一次，讓她看見「縮排位置＝什麼時候做」。這是今天最關鍵的觀念。
total += damage 提一下就好，她想用再用。

Part 2

random：讓遊戲每次都不一樣

擲骰子與掉寶

打開 03-random.py連續執行三次，看結果不一樣
import random     # 借用工具箱

roll = random.randint(1, 100)
print(f"骰出了 {roll}")

drops = ["生鏽的劍", "紅藥水",
         "金幣 x10", "什麼都沒有"]
print(random.choice(drops))

兩個好用的

randint(1, 100)
隨機一個整數，含頭含尾

choice(清單)
從清單裡隨機挑一個

為什麼遊戲要亂數

每次都一樣就不好玩了——掉寶、暴擊、抽卡、怪物位置，全都是亂數。

import 只要說「借用別人寫好的工具箱」，不要講模組系統。
讓她執行三次看到不同結果——這一刻她會理解亂數。
接著把上一頁的固定傷害改成 random.randint(10, 20)，五連段每次都不同，串起 for + random。
中括號的清單今天只要會用 choice 就好，下一堂才正式教清單，不要展開。

Part 3

while：不知道要跑幾次

打到倒下為止

打開 04-while.py執行幾次，回合數每次不同
hp = 100
turn = 0

while hp > 0:
    turn = turn + 1
    damage = random.randint(10, 25)
    hp = hp - damage
    print(f"第 {turn} 回合，剩 {hp}")

print(f"撐了 {turn} 回合")
什麼時候用
for知道要跑幾次
五連段、十個怪
while只知道什麼時候停
打到血量歸零

這就是為什麼戰鬥要用 while——誰知道要打幾回合？

先問她：「一場戰鬥要打幾回合？」她答不出來 → 「所以 for 不夠用」。這個提問順序很重要。
條件寫的是「繼續的條件」不是「結束的條件」，她很容易寫反成 while hp <= 0（一次都不跑）。讓她試一次看看。

無窮迴圈：迴圈停不下來

❌ 永遠停不下來

hp = 100
while hp > 0:
    print("攻擊！")

血量從來沒有變少，條件永遠成立

✅ 會結束

hp = 100
while hp > 0:
    print("攻擊！")
    hp = hp - 10

每輪血量減少，總有一天 ≤ 0

卡住了怎麼辦：在終端機按 Control + C，強制停掉。
每次寫 while 都要問自己一句：哪一行會讓條件變成不成立？
一定要現場示範一次無窮迴圈，讓畫面狂噴，再按 Control+C 停掉。她會記一輩子，而且以後不會怕。
（上一堂在工坊也遇過，那時是 20 秒自動停。真的 Python 不會自動停，只能自己按。）
break 在這裡順帶講：迴圈裡遇到 break 就直接跳出去，不管條件成不成立。上堂的猜數字就用過。
