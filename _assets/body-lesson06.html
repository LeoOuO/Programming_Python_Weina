第 6 堂 · 專題：你的第一個完整遊戲

Slime Tower

今天不學新語法，把前五堂全部組起來，做一個能玩到破關的遊戲。

這堂是里程碑：她要意識到「我已經會做遊戲了」。
課前先自己完整玩一次 game.py（會贏，大約 8～10 分鐘），確認她的電腦跑得動。
今天最重要的產出是「她改過的那一版遊戲」，不是進度。

今天要做的事

段落大約做什麼
1. 先玩一次15 分玩 Slime Tower，邊玩邊猜它怎麼寫的
2. 拆開來看25 分資料／函式／主程式三層結構
3. 遊戲主迴圈20 分選單迴圈、遊戲狀態字典
休息 5 分鐘
4. 練習兩階段30 分填空迷你版 → 改造成自己的遊戲
5. 展示20 分她玩你的、你玩她的
最後 20 分鐘的互相試玩不要砍——這是整個階段的收尾儀式。你要認真玩她的版本並給具體回饋（哪一層太難、哪句話好笑）。

先玩一次

打開 game.py直接執行，玩到破關或倒下

讓她玩，你在旁邊只看不說。玩完問三個問題：
① 你覺得哪一步決定輸贏？（答案通常是「有沒有買劍」）
② 這個遊戲裡有幾種資料？（角色、怪物、商品）
③ 如果要加第六層，你覺得要改幾個地方？（她可能會說很多，其實只要一個）
什麼都不買的話幾乎一定會輸，買了裝備就贏得了——這是刻意設計的，讓商店有意義。

第 2 堂的迴圈

為什麼要分三層？改數值只動①，改玩法只動②，改流程只動③—— 不會「改一個地方，壞三個地方」。
打開 game.py 用 O 鍵式的快速捲動帶她看一遍：上面是資料、中間是函式、最下面是主程式。
問她「battle() 裡面有沒有用到今天以前學的東西？」→ while、if、random、字典，全部都有。讓她自己找出來，會很有成就感。
不要逐行講解整支程式，重點是看懂結構。

遊戲狀態：把進度放在一個字典裡

打開 02-game-state.py執行看看
game = {
    "hero": {"name": "Luna", "hp": 100, "max_hp": 100, "atk": 15},
    "gold": 50,
    "potions": 1,
    "floor": 1,
}

print(game["hero"]["name"])       # 字典裡面還有字典，一層一層拿
game["gold"] = game["gold"] + 40  # 打贏一場，金幣增加
整個遊戲的「現在進度」都在這一包。之後要做存檔，也只要把這一包存起來。
game["hero"]["hp"] 兩層要拆開念：先拿 hero（一個字典），再拿它的 hp。
可以順口提一下：存檔就是把這個字典寫進檔案，讀檔就是讀回來——下一個階段會學。不用展開。

主迴圈：遊戲為什麼不會停

打開 01-menu-loop.py執行，玩到你按 3 為止
playing = True

while playing:
    print("1) Work  2) Rest  3) Quit")
    choice = input("Choose: ")

    if choice == "1":
        gold = gold + 30
    elif choice == "3":
        playing = False     # 條件變 False -> 停
    else:
        print("That is not an option.")

所有遊戲都長這樣

顯示畫面 → 等玩家輸入 → 照著做 → 回到第一步

手機遊戲一秒鐘跑 60 次這個迴圈，只是快到你看不見。

else: 那段很重要：玩家一定會亂按

「遊戲迴圈 game loop」是遊戲程式最核心的概念，之後學 pygame 第一件事就是它。今天先用文字版建立直覺。
讓她故意亂按（輸入 9、輸入空白），看 else 接住——好的程式要預期玩家亂按。

換你寫 ②：把遊戲變成你的

打開 practice-2.py照清單改 game.py，改一項玩一次
  • 1. 換皮名稱、怪物、商品換成你的主題
  • 2. 第六層MONSTERS 加一隻，主程式不用改
  • 3. 新商品SHOP 加一項 + 一個 elif
  • 4. 新技能戰鬥選單加第 4 個選項
  • 5. 難度調整玩三次，調到「有點難但打得過」
  • 6. 挑戰：戰績畫面通關時印打贏幾場、賺多少
  • 7. 挑戰：寶箱事件每層 30% 機率撿到金幣
第二階段 20 分鐘起跳，做不完是正常的，1、2、5 一定要做到（換皮最有動力、第六層證明結構的好處、調難度是遊戲設計）。
第 5 項是今天的靈魂：讓她自己玩三次、自己決定數值——這是她第一次做「遊戲設計師」的工作。
她一定會問「可以加＿＿嗎？」——只要她說得出做法就讓她做，做壞了正好練除錯。

Part 3

互相試玩

展示時間

你玩她的版本

  • 你會怎麼改這個遊戲？

做遊戲的人一定要看別人玩自己的遊戲——卡住的地方，玩的人不會說，但看得出來。
你的版本先改幾個地方（多一層、換個主題），讓她有得比較。
「下一個想做什麼遊戲」的答案記下來，那是下一階段（pygame）的專題方向。
