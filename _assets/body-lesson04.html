一個很煩的問題

現在的寫法

print("=" * 30)
print("  WELCOME, HERO!")
print("=" * 30)

# ...中間一堆程式...

print("=" * 30)
print("  WELCOME, HERO!")
print("=" * 30)

想把框線改成 *？兩個地方都要改，漏掉一個就不一致

用函式

def greet():
    print("=" * 30)
    print("  WELCOME, HERO!")
    print("=" * 30)

greet()
# ...中間一堆程式...
greet()

改一個地方，所有用到的地方一起變

Part 1

第一個函式

定義與呼叫

打開 01-my-first-function.py執行看看，再多呼叫幾次
def greet():            # ① 定義（define）
    print("WELCOME!")
    print("=" * 20)


greet()                 # ② 呼叫（call）
greet()                 # 想叫幾次就叫幾次

四個規則

  • def + 名字 + () + 冒號
  • 裡面的程式要縮排
  • 定義不會執行，只是先寫好放著
  • 要呼叫（打名字加括號）才會動

如果只有 def greet(): ...，後面沒有寫 greet()，執行後會印出幾行字？

答案 0。「定義 ≠ 執行」是今天第一個坎，現場示範：把 greet() 那兩行註解掉，執行 → 什麼都沒有。
比喻：定義＝寫食譜，呼叫＝照食譜做菜。寫好食譜不會自己生出菜來。
函式名稱的規矩跟變數一樣：英文小寫、用底線連接，例如 show_title。

Part 2

參數與回傳

把資料傳進去：參數

打開 02-parameters.py加一個自己的角色進去
def attack(name, damage):            # 括號裡是「參數」parameter
    print(f"{name} attacks for {damage} damage!")


attack("Hero", 12)                   # Hero attacks for 12 damage!
attack("Slime King", 20)             # Slime King attacks for 20 damage!

參數是什麼

函式裡面的空格，呼叫的時候才填進去。
同一個函式可以用在任何角色身上。

預設值

def heal(name, amount=30):

呼叫時不給 amount 就用 30

先讓她看只有一行 print 的版本，再問「那要印十個角色呢？」→ 參數的必要性。
順序很重要：attack("Hero", 12) 的 "Hero" 對到 name、12 對到 damage，位置對應。可以故意寫反 attack(12, "Hero") 看結果多好笑。
常見錯誤：定義時忘了寫參數，函式裡卻用了那個名字 → NameError。練習第 2 題就是這個。

把答案拿回來：return

打開 03-return.py最後一個 Try it 一定要試
def damage_of(atk, defense):
    damage = atk - defense
    if damage < 1:
        damage = 1
    return damage        # 把答案交回去


d = damage_of(20, 5)     # d 收到 15
total = damage_of(20, 5) + damage_of(15, 3)
做什麼
print印出來給人看，程式拿不到
return把值交回程式，可以再拿去算

回傳 True / False

def is_alive(hp):
    return hp > 0

if is_alive(35):
    print("still standing!")
print 和 return 的差別是今天第二個坎，而且最容易混。
示範：把 return damage 改成 print(damage)，然後 d = damage_of(20, 5) → d 變成 None，d + 3 直接報錯。看到才會懂。
is_alive 這種回傳 True/False 的函式，讓程式讀起來像英文句子，Demo 裡用了很多次。

一次回傳兩個東西

打開 04-skills.py加一個自己的技能
def fireball(atk):
    if random.randint(1, 100) <= 25:
        return 0, "Fireball misses!"
    damage = atk * 2
    return damage, f"FIREBALL! {damage}"


damage, text = fireball(12)   # 一次收兩個
print(text)

技能系統的做法

每個技能 = 一個函式，都回傳 (傷害, 訊息)。

要加新技能？再寫一個函式就好，戰鬥的程式完全不用動。

這就是為什麼真的遊戲可以有幾百個技能

回傳兩個值用逗號隔開，接的時候也用逗號：damage, text = fireball(12)。她上一堂看過 for i in range(len(...))，這個也是「一次拿兩個」的概念。
讓她照著 slash 的樣子寫一個自己的技能（名字、倍率、機率自己定），寫完馬上在 Demo 裡用得到——這是今天最有成就感的一步。
