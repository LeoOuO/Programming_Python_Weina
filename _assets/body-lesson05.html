一個角色 = 一包資料

清單是一排東西，用位置（0、1、2）拿。
字典是一組有名稱的資料，用名稱拿——像查字典一樣。
開場問她：「上禮拜的地城，如果每隻怪都要有名字、血量、攻擊力、掉落金幣，你會怎麼存？」
她可能會說用清單 ["Slime", 30, 9, 25]——很好！那就追問「30 是血量還是攻擊力？」數字沒有名字，很容易記錯，字典就是來解決這個的。

Part 1

字典怎麼用

用名稱存取

打開 01-dict.py改成你自己的角色
hero = {
    "name": "Luna",      # "名稱": 值
    "hp": 100,
    "atk": 18,
}

print(hero["name"])      # Luna
hero["hp"] = 70          # 改一項
hero["level"] = 5        # 加一項（本來沒有）

三個規則

  • 用大括號 { }，清單是中括號 [ ]
  • 每項是 "名稱": 值，名稱要加引號
  • 取值用 hero["hp"]，不是數字位置

名稱的正式說法叫 key（鍵），值叫 value

字典裡沒有 "mana" 這一項，卻寫 print(hero["mana"])，
會看到哪一種錯誤？（填錯誤的名字）

答案 KeyError：找不到這個鍵。讓她真的執行一次看訊息——她已經認得 NameError、IndexError，這是第三種。
注意 f-string 裡面要用不同的引號：f"{hero['name']}"（外面雙引號、裡面單引號），她一定會踩到。

Part 2

一整隊、一整本圖鑑

清單裡面放字典

打開 02-list-of-dicts.py加第四個角色進去
party = [
    {"name": "Luna",  "hp": 100, "atk": 18},
    {"name": "Borin", "hp": 140, "atk": 12},
    {"name": "Sera",  "hp": 80,  "atk": 24},
]

print(party[0]["name"])            # 第 0 個角色的名字 -> Luna

for member in party:               # 一個一個拿出來，每個都是字典
    print(f"{member['name']} has {member['hp']} HP")
這是遊戲資料的標準做法。怪物圖鑑、道具表、隊伍、排行榜——全部都是「清單裡放字典」。
party[0]["name"] 兩層要拆開念：先拿第 0 個（一個字典），再拿它的 name。可以在互動模式裡一層一層印給她看。
「找最強的」那段（用 best 存目前最好的，再一個一個比）是第三堂學過的招數換個包裝，指出來讓她有「我學過」的感覺。

商店：名稱對價格

打開 03-shop.py加兩樣新商品
prices = {
    "Potion": 20,
    "Iron Sword": 80,
    "Shield": 60,
}

for item in prices:        # 跑字典會拿到「名稱」
    print(item, prices[item])

if prices["Shield"] <= gold:
    gold = gold - prices["Shield"]
    bag.append("Shield")

買東西的三步驟

① 錢夠不夠？if 價格 <= gold
② 扣錢 gold = gold - 價格
③ 放進背包 bag.append(...)

任何遊戲的商店都是這三步

for item in prices 拿到的是名稱不是值，這點要講清楚，她會以為拿到價格。
三步驟的順序不能亂：先檢查再扣錢。問她「如果先扣錢再檢查會怎樣？」→ 錢變負的，這是真的遊戲會出的 bug。
