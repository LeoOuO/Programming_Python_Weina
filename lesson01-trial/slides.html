Part 2

遊戲是怎麼做出來的？

把一個遊戲拆開來看

拿你剛剛說的那個遊戲來看，它大概由四種東西組成：

看到的

角色、背景、按鈕、特效

→ 美術

聽到的

音樂、音效、配音

→ 音樂

怎麼反應

點一下會怎樣、撞到會怎樣、什麼時候贏

→ 程式

好不好玩

關卡、難度、獎勵、劇情

→ 遊戲設計

程式負責的是哪一部分？

負責所有的「規則」：碰到牆會怎樣、分數怎麼算、什麼時候出現下一關、存檔怎麼存…… 沒有程式的話，畫面只是一張圖，不會動、也不會理你。

用她說的遊戲一格一格對照，每格都問她「這個遊戲的○○是什麼？」讓她自己填。 例：貪食蛇 → 看到的：蛇、食物；聽到的：吃到的音效；反應：撞牆就結束、吃到會變長；設計：越吃越快。
目的：讓她發現「做遊戲」不是一個神祕的東西，是四塊拼圖，而程式只是其中一塊——但是讓東西動起來的那一塊。
如果她第 4 頁說了會畫畫／音樂，這裡要接：「所以你其實已經有一塊了，我們今天補那個⚙️。」

先說清楚：Python 本身不太拿來直接做手機 app。我們先用它學第 1 項，因為這一項最花時間， 而且學會之後換到遊戲引擎，寫法差不多，只是工具不同。
這頁是誠實的路線圖，也是給家長聽的（如果家長在旁邊）。不要騙她「學 Python 就能做手機遊戲」， 但要讓她知道 Python 是正確的第一步：
· 程式思維（變數／判斷／迴圈／清單／函式）在所有語言都一樣，Python 語法最少、最快上手
· Godot 的腳本語言 GDScript 長得幾乎跟 Python 一樣，這是之後銜接手機遊戲最自然的路（免費、可輸出 iOS/Android）
· 中間可以用 pygame 在電腦上做 2D 小遊戲，直接練 1️⃣ 的內容
暫定路線：Python 基礎（8～10 堂）→ pygame 電腦小遊戲（一個專題）→ Godot（手機）。這個要跟家長確認，不要在課堂上承諾堂數。

程式是什麼

寫給電腦看的步驟說明

泡麵說明（給人看）

  1. 把水煮開
  2. 放麵、放調味包
  3. 等 3 分鐘
  4. 如果太鹹，加一點水

程式（給電腦看）

print("把水煮開")
print("放麵、放調味包")
for i in range(3):
    print("等 1 分鐘")
salty = input("太鹹嗎？")
if salty == "是":
    print("加一點水")

差別是：電腦只會照字面做，你少寫一步它就不做那一步。

重點只有一句：程式就是一步一步的指令。右邊的程式碼和左邊一步對一步：兩行 print 對應步驟 1、2，for 那兩行對應「等 3 分鐘」（重複 3 次「等 1 分鐘」）， input＋if 對應「如果太鹹，加一點水」（程式不會嚐味道，所以先問你鹹不鹹）。不用逐行解釋語法，只要指出對應關係，讓她看到左右兩邊長得像。她如果問「為什麼要加括號」之類的，回答「等一下你自己打的時候就知道了」，不要在這裡展開語法。

先真的玩一局（你想數字，她猜；再換她想、你猜）。你猜的時候故意用「對半猜」（10 → 15 → 12…），玩完問她「你有發現我怎麼猜的嗎？」——這是二分搜尋的種子，不用講名字。
然後指著流程圖說：「這就是這個遊戲的全部規則，四格。程式就是把這四格打出來。」
下面三個盒子對應第 6 頁「程式怎麼想」的三件事，讓她看到：一個遊戲 = 這三件事的組合。

寫成程式

切到工坊 ② 猜數字遊戲先玩三局，再回來看程式開工坊 ↗

1) 整支程式

import random
answer = random.randint(1, 20)   # 電腦偷偷選
count = 0

while True:                        # 一直重複
    guess = int(input("猜一個 1~20 的數字："))
    count = count + 1
    if guess > answer:
        print("太大了！")
    elif guess < answer:
        print("太小了！")
    else:
        print("猜中了，你猜了", count, "次")
        break                      # 結束重複

2) 每一行在做什麼

程式白話
random.randint(1, 20)從 1～20 隨機抽一個
while True:「一直重複下面縮排的部分」
int(input(...))問你、然後把你打的當成數字
if / elif / else如果…／不然如果…／不然就…
break跳出重複，遊戲結束
工坊按鈕②就是這支程式（加了註解）。先讓她玩三局再看程式，玩過再看會覺得每一行都「理所當然」。
講的順序：對照流程圖四格 → 找出每格在程式的哪一行。不要逐行講語法，只講「這行 = 流程圖的哪一格」。
縮排要點一下：「縮進去的這幾行是『重複的內容』，Python 用縮排看誰是誰的小弟。」
int(...) 她一定會問或忽略：input 收到的是「字」，要變成「數字」才能比大小——用「"5" 是一個符號，5 才是數量」帶過即可。

電腦是怎麼跑這支程式的

假設它選到 7，你依序猜 5、9、7。按「下一步」看每個盒子的值怎麼變。

選用頁。如果她在前一頁已經看懂、而且時間不夠，直接跳過。 如果她問「電腦怎麼知道要回去再猜」，這頁就很有用：讓她自己按下一步，看 count 怎麼加、看黃色那行怎麼跳。
不要讓她填表，只是看。填表是之後的功課，不是試教的事。

改成你的版本

切到工坊 ② 猜數字遊戲改完按執行試玩，做完一個勾一個開工坊 ↗

從這裡挑，或自己想：

  • 改範圍1～100，變難；或 1～5，變簡單
  • 改台詞「太大了」換成你自己的講法
  • 猜太多次有反應超過 5 次的話，多印一句話
  • 差 1 的時候提示印「很接近了」
  • 猜中時多印幾行用重複做，印 5 行星號
  • 先問名字猜中時印「○○ 猜對了」
這 20 分鐘是試教的核心，讓她擁有這支程式。她想改什麼就改什麼，清單只是沒靈感時的菜單。
參考解法（只在她卡住時逐步提示，不要直接打給她）：
· 改範圍：randint(1, 100)，提示字也要改
· 猜太多次：在 else 裡加 if count > 5: print("猜了不少次")
· 差 1：在 if 之前 if abs(guess - answer) == 1: print("很接近了")（abs 先說「距離」就好）
· 多印幾行：for i in range(5): print("*" * 10)（順便看到字串乘法）
· 名字：開頭 player = input("你的名字：")，猜中印 player + " 猜對了"
做到一半時間到就停，先存好、先秀，不要為了做完而趕。

t = turtle.Turtle()
t.speed(0)

工坊按鈕 ③。執行後試著改：

  • left(59) → 改成 90、121、178 看看
  • 把顏色換成你喜歡的（"pink"、"gold"、"cyan"）
  • range(120) → 改成 300

遊戲畫面基本上也是這樣一筆一筆畫的，只是速度快很多。

畫圖需要幾秒鐘（120 步），畫的時候下面會慢慢出現，不是當機。不要在這裡解釋 %，只說「六個顏色輪流用」。

剪刀石頭布

切到工坊 ⑥ 剪刀石頭布先玩五局，再看程式開工坊 ↗
import random
choices = ["剪刀", "石頭", "布"]
computer = random.choice(choices)
me = input("你出什麼？")
print("電腦出：" + computer)
if me == computer:
    print("平手")
elif me == "剪刀" and computer == "布":
    print("你贏了")
elif me == "石頭" and computer == "剪刀":
    print("你贏了")
elif me == "布" and computer == "石頭":
    print("你贏了")
else:
    print("你輸了")

新東西只有一個

["剪刀", "石頭", "布"] 是一個清單：把好幾個東西排在一起。
random.choice(...) 從裡面隨機拿一個。

其他都學過了

input 問你、if / elif / else 判斷誰贏——跟猜數字一樣，只是條件變多。

為什麼要寫三個「你贏了」？

因為贏的情況有三種，電腦要一種一種比。少寫一種，那種情況就會跑到最後的 else，被判成輸。

重點是讓她發現「這支程式我幾乎都看得懂」——清單是唯一的新概念，用「一排盒子」講就好。
先玩五局。她大概會問「電腦怎麼知道我出什麼」→ 指 me = input(...)；「電腦是不是作弊」→ 指 random.choice 是在你輸入之前就決定了，可以把 print("電腦出：") 搬到 input 前面證明。
常見錯誤：輸入「剪刀 」多一個空格、或輸入「剪」→ 四個條件都不符 → 印「你輸了」。這是講「電腦只認完全一樣的字」的好機會，備註不用主動講，等她遇到。

改一改

切到工坊 ⑥ 剪刀石頭布挑一個改，改完玩幾局開工坊 ↗
  • 輸入錯字時提醒如果 me 不在清單裡，印「請輸入剪刀、石頭或布」
  • 玩三局用 for 把整段包起來，重複 3 次
  • 算分贏一局 +1，最後印「你贏了 N 局」
  • 加第四種拳自己發明一種，規則你決定
參考解法（卡住才逐步提示）：
· 輸入檢查：if me not in choices: print("請輸入剪刀、石頭或布")，放在比較之前；not in 直接念成中文就懂
· 三局：for i in range(3): 然後整段往右縮 4 格——工坊裡選取多行按 Tab 會一起縮，可以示範
· 算分：開頭 win = 0，每個「你贏了」下面加 win = win + 1，迴圈結束後 print("你贏了", win, "局")
· 第四種拳：她自己想規則，會發現 elif 要多寫好幾條——這是之後講「用表格／字典存規則」的伏筆，今天不展開。

抽籤機

切到工坊 ⑦ 抽籤機把清單換成你自己的開工坊 ↗
import random
dinner = ["滷肉飯", "拉麵", "披薩", "水餃", "咖哩"]
print("今天晚餐吃：" + random.choice(dinner))

for i in range(3):
    print("第", i + 1, "次抽到：" + random.choice(dinner))

清單裡放什麼都可以：要看的影片、假日要去哪、誰先洗碗。

改成你的

  • 把清單換成你自己的選項（幾個都行）
  • 改成抽 10 次
  • 做兩個清單：一個「吃什麼」、一個「在哪吃」，各抽一個印成一句話
這頁很短，目的是讓她帶一個「真的會用到」的小工具回家。兩個清單那題答案： 
place = ["家裡", "學校旁邊", "夜市"]
print("今天在" + random.choice(place) + "吃" + random.choice(dinner))
順便講一下 + 接字串時中間不會自動加空格，所以中文句子要自己排好。
