Part 1

背包：清單怎麼用

拿出其中一樣：編號從 0 開始

打開 01-bag.py執行，然後試 bag[10] 看錯誤訊息
bag = ["Wooden Sword", "Red Potion", "Bread"]

print(bag[0])    # Wooden Sword
print(bag[1])    # Red Potion
print(bag[-1])   # Bread（倒數第一個）
print(len(bag))  # 3（有幾樣）
編號012
東西Wooden SwordRed PotionBread
倒數-3-2-1

三樣東西，編號是 0、1、2——沒有 3。
跟上堂 range(3) 一樣的規矩。

讓她真的打 bag[3] 執行 → IndexError: list index out of range → 一起讀這行英文。她已經看過工坊的中文翻譯，現在看原文剛好。
bag[-1] 很實用（最後一個），她會很喜歡。

撿東西、用東西

bag.append("Iron Sword")   # 撿到 → 加到最後面
bag.remove("Red Potion")   # 用掉 → 拿走這一個
bag[0] = "Steel Sword"     # 換掉第 0 格
['Wooden Sword', 'Red Potion', 'Bread'] ['Wooden Sword', 'Red Potion', 'Bread', 'Iron Sword'] ['Wooden Sword', 'Bread', 'Iron Sword'] ['Steel Sword', 'Bread', 'Iron Sword']

常用動作

.append(x)加到最後
.remove(x)拿掉那一個
len(清單)有幾個
x in 清單在不在裡面

.append() 前面是清單的名字，不是 print

bag.append(...) 的「點」句型她第一次看到，說法：「叫這個清單去做一件事」，不要講方法／物件。
示範 remove 一個不存在的東西 → ValueError，順便複習讀錯誤。
空清單 bag = [] 要特別講，Demo 的背包就是從空的開始。

Part 2

走訪：一次處理一整排

for 直接把清單跑一遍

打開 02-party.py執行，看兩種寫法差在哪

只要內容

for member in party:
    print(f"- {member}")

member 每輪裝一個隊員

要編號也要內容

for i in range(len(party)):
    print(f"{i + 1}. {party[i]}")

i 是位置，party[i] 是內容

party = ["Swordsman", "Mage", "Archer", "Healer"]，
for x in party: 這個迴圈會跑幾輪？

答案 4：有幾個就跑幾輪，不用自己數。
兩種寫法都要會：只印內容用左邊，要編號（或要同時對照另一個清單）用右邊。hp_list[i] 就是右邊的典型用途。

一行算出統計

hp_list = [120, 70, 90, 80]

print(len(hp_list))      # 4      幾個
print(sum(hp_list))      # 360    總和
print(max(hp_list))      # 120    最大
print(min(hp_list))      # 70     最小
print(sum(hp_list) / len(hp_list))   # 90.0   平均
上一堂要用迴圈慢慢累加的總和，清單一個 sum() 就好。
但「只算血量大於 80 的總和」還是要 for + if——工具愈多，選擇愈多。
對照上堂的累加，讓她感覺到「工具會越來越省事」。
但要強調 sum/max 只能做固定的事，有條件時還是得自己寫迴圈——這就是練習 4。
sorted() 快速帶過：排名榜用得到。

Part 3

抽卡的祕密

機率是怎麼做出來的？

打開 03-gacha.py執行十連抽
pool = (["SSR Dragon Knight"] * 2
      + ["SR Fire Mage"] * 8
      + ["R Archer"] * 30
      + ["N Villager"] * 60)

card = random.choice(pool)

["A"] * 3 → ["A", "A", "A"]
清單也可以用乘法複製

原理超簡單

把卡池做成 100 張的清單：
SSR 放 2 張、SR 放 8 張、R 放 30 張、N 放 60 張。

然後 random.choice 隨便抽一張——
抽到 SSR 的機率自然就是 2%。

這頁是今天的高潮，她會有「原來是這樣！」的反應。
問她：「如果要做 0.5% 的機率呢？」→ 卡池放 1000 張、SSR 放 5 張。她就懂了比例。
可以聊一下真實遊戲的保底機制（抽 N 次必出），問她要怎麼做——答案是「數抽了幾次」，也就是上堂的累加。不用真的實作，讓她知道她已經有工具了。

把抽到的收進背包

results = []                       # ① 空清單

for i in range(10):
    card = random.choice(pool)
    results.append(card)           # ② 抽到就放進去
    print(f"{i + 1}. {card}")

print(results.count("SSR Dragon Knight"))   # ③ 統計
這就是上一堂累加的清單版：空清單 → 迴圈裡 append → 迴圈外統計。 .count(x) 數某個東西出現幾次。
三步驟的結構跟上堂的 total = 0 完全一樣，明講出來：「準備 → 迴圈裡累積 → 迴圈外結算」是寫程式最常見的骨架。
常見錯誤：results = [] 放進迴圈裡（每輪清空，最後只剩一張）。可以故意示範。
